# foodapp (RescueBite)

Surplus-food rescue mobile app built with **Expo** and **React Native** — browse Surprise Bags, reserve pickup, manage orders, vouchers, and account settings.

## Stack

- Expo SDK 57 + Expo Router
- React Native + TypeScript
- Zustand, React Query
- React Native Reanimated / Gesture Handler

## Run locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `w` for web / `a` for Android emulator.

## Project layout

- `app/` — screens and routes
- `src/components/` — UI and feature components
- `src/hooks/` — data hooks
- `src/services/` — API / local mock backend
- `src/store/` — Zustand stores
- `src/theme/` — design tokens
